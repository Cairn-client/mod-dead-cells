# Dead Cells Multiplayer Mod on Cairn

A fork of [vaiserYT/DeadCellsMultiplayerMod](https://github.com/vaiserYT/DeadCellsMultiplayerMod), the multiplayer mod for **Dead Cells**, made to run on the [Cairn launcher](https://github.com/Cairn-client/launcher).

## What we changed

- A Cairn pack: the mod and the Dead Cells Core Modding API are published as a pack the launcher installs and updates; Play starts the game through the modding launcher.

The mod's own code and credits are its authors'. Everything else is as upstream; see [UPSTREAM.md](UPSTREAM.md) for the version this fork is based on.

## Play it

1. Install [Cairn](https://github.com/Cairn-client/launcher/releases/latest).
2. Open Dead Cells in the Library, download the mod and press Play.

Each release of this repository is the pack the launcher downloads.
